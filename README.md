Aplicación interactiva de decisión multicriterio para comparar tres alternativas según tres factores de riesgo editables. Permite asignar pesos porcentuales, consultar las matrices normalizada y ponderada y explorar las soluciones ideal y antiideal en un gráfico 3D, junto con sus respectivas distancias euclídeas.

[Abrir la app](https://paburgip.github.io/SolucionIdeal/)
