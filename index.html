Entender el cálculo ＋

Para cada alternativa, comparamos sus tres valores con el vector ideal z*. Todos los criterios usan una escala fija de 0 a 100.

dp(i) = [ Σj=1…3 wj · ( |xij − z*j| / 100 )p ]1/p

Los pesos efectivos son wj = pesoj / Σ pesos. Con p = 1 se obtiene la distancia Manhattan ponderada; con p = 2, la euclídea ponderada. Se ponderan las potencias de las desviaciones, antes de extraer la raíz.

El ideal de escala es 100 cuando más es mejor y 0 cuando menos es mejor. El ideal observado combina el mejor valor de cada criterio, aunque proceda de alternativas diferentes. Los datos iniciales no alcanzan ninguno de esos dos vectores ideales.

La normalización divide entre 100, el rango fijo de la escala; no cambia al editar las alternativas. Un peso 0 excluye su criterio del cálculo. Puede haber empates o distancia 0 sin coincidencia completa con el ideal si algún criterio tiene peso 0. La distancia depende de tus preferencias; no expresa una probabilidad ni una recomendación universal.

El gráfico 3D representa cada alternativa como un punto y el ideal como un rombo. Los ejes se orientan para que un valor mayor sea mejor (100 − valor en criterios que se minimizan), se dividen entre 100 y se multiplican por wj1/p. Así, la distancia de orden p entre los puntos coincide con el cálculo. Con p = 2, los segmentos muestran la distancia euclídea en ese espacio; con otros valores de p, usa las etiquetas numéricas. Girar, desplazar o ampliar la vista no cambia los datos ni las distancias. Este laboratorio mide la distancia al ideal positivo; no calcula el índice TOPSIS.
